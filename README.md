# ヘルスナビ — 脂質改善 × 減量 × 筋肥大 管理アプリ

毎日 **30秒** で「今日なにを食べ、どう動けばよいか」を決められる健康管理アプリの MVP です。

## コンセプト

- **3つの軸を同時に支援**: 中性脂肪・コレステロール改善、体脂肪の減量、筋肥大
- **行動中心の UX**: ホーム画面は「次にやること」だけ。情報過多を排除
- **提案 = 記録**: 提案された食品をタップするとそのまま記録完了
- **禁止リストではなく置換提案**: 「○○をやめろ」ではなく「△△に替えよう」

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開くと `/today` にリダイレクトされます。

初回は **設定ページ** でプロフィール（身長・体重・目標・活動量）を入力してください。

## 画面構成

| パス | 機能 |
|---|---|
| `/today` | **ホーム** — 今日の作戦カード、次の食事提案、運動、スコア |
| `/log/meal` | 食事記録 — 検索→量→確定 の最短フロー |
| `/log/workout` | 運動記録 — 筋トレ A/B 完了 + RPE + 歩数 |
| `/weekly` | 週次レビュー — スコア推移、良かった点、改善点 |
| `/library/favorites` | 食品ライブラリ — 定番登録・カスタム食品追加 |
| `/settings` | プロフィール — 身長体重、目標、活動量、採血値 |

## 技術スタック

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS v4** — カードUI中心のモバイルファーストデザイン
- **Dexie.js** (IndexedDB) — ローカル完結、サーバー不要
- **提案エンジン** — ルールベース（`src/lib/engine.ts`）

## 設計

### データモデル (`src/lib/db.ts`)

- `UserProfile` — 身長、体重、目標、活動量、採血値
- `FoodItem` — 食品マスタ（カロリー、P、食物繊維、飽和脂肪）
- `MealLog` — 食事記録（食品×量の配列 + 合計値）
- `WorkoutPlan` — 筋トレテンプレート A/B
- `WorkoutLog` — 筋トレ実施記録 + RPE
- `DailySummary` — 日次集計 + 3スコア
- `WeeklySummary` — 週次レビュー

### スコア設計

3つのスコア（0-100）をユーザーに表示:

1. **脂質スコア** — 食物繊維到達度(40%) + 飽和脂肪制限(30%) + 活動量(20%) + カロリー(10%)
2. **減量スコア** — カロリー管理(60%) + 活動量(25%) + 筋トレボーナス(15%)
3. **筋肉スコア** — たんぱく質到達度(50%) + 筋トレ実施(40%) + ベース(10%)

### 提案エンジン (`src/lib/engine.ts`)

優先順位ベースで最大2つの提案を生成:

1. 食物繊維不足 → 海藻・豆・野菜を「足す」
2. 飽和脂肪過多 → 赤身・魚への「置換」
3. たんぱく質不足 → 高たんぱく食品を「足す」
4. カロリー超過 → 低カロリー食材で「置換」

- `computeScores` — スコア計算の正確性
- `suggestNextActions` — 不足→提案の正しさ
- `generateStrategyCard` — 作戦カードの生成
- `getTodayWorkoutPlan` — 曜日別プラン判定
- `generateWeeklyHighlight` — 週次ハイライト生成
